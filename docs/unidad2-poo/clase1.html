📘 Clase 1 - Introducción a la POO

Clases, objetos y atributos

🧠 ¿Qué es la POO?

La Programación Orientada a Objetos (POO) es una forma de programar donde organizamos el código en objetos.

👉 En vez de pensar en pasos, pensamos en:

  • Qué cosas existen
  • Qué características tienen

🎮 Ejemplo: Videojuegos

En un videojuego no se crea cada personaje manualmente.

  • Clase: Heroe
  • Objetos: Artigas, Mago, Guerrero

🧱 ¿Qué es una clase?

Una clase es un molde que define cómo serán los objetos.

Heroe
---------
nombre : String
clase : String
nivel : int

👤 ¿Qué es un objeto?

Un objeto es una instancia de una clase.

🧾 Atributos


public class Heroe {
    public String nombre;
    public String clase;
    public int nivel;
}

🆕 Crear objetos


Heroe h1 = new Heroe();

✏️ Asignar valores


h1.nombre = "Artigas";
h1.clase = "Guerrero";
h1.nivel = 1;

🧬 Identidad de los objetos


Heroe h1 = new Heroe();
Heroe h2 = new Heroe();

h1.nombre = "Artigas";
h2.nombre = "Mago";

✔ Cada objeto es independiente

✔ No comparten datos

⚠️ Error común

❌ Pensar que cambiar un objeto afecta a todos

✔ Cada objeto tiene su propia información

  • Clase = molde
  • Objeto = instancia
