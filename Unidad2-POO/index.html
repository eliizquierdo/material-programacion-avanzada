📘 Introducción a la Programación Orientada a Objetos (POO)

🧠 1. ¿Qué es la Programación Orientada a Objetos?

La Programación Orientada a Objetos (POO) es un paradigma de programación que permite organizar el código creando objetos que representan elementos del mundo real.

👉 En lugar de pensar en “pasos a seguir”, pensamos en:

  • Qué cosas existen (objetos)
  • Qué características tienen (atributos)

🎮 2. Analogía: Videojuegos (RPG)

Imaginemos un videojuego:

  • No se programa cada personaje uno por uno
  • Se crea un molde (clase)
  • Luego se crean múltiples personajes (objetos)

👉 Ejemplo:

  • Clase: Heroe
  • Objetos: “Artigas”, “MagoOscuro”, “Guerrero1”

🧱 3. ¿Qué es una Clase?

Una clase es un molde o plantilla que define cómo serán los objetos.

Define:

  • Qué datos tendrán (atributos)
  • (Más adelante veremos métodos)
Heroe
---------
nombre : String
clase : String
nivel : int

👤 4. ¿Qué es un Objeto?

Un objeto es una instancia de una clase.

👉 Es un elemento concreto creado a partir del molde.

🧾 5. Atributos

Los atributos son las características o datos de un objeto.


public class Heroe {
    public String nombre;
    public String clase;
    public int nivel;
}

🆕 6. Crear Objetos

Para crear un objeto usamos la palabra clave new.


Heroe h1 = new Heroe();

✏️ 7. Asignar valores


h1.nombre = "Artigas";
h1.clase = "Guerrero";
h1.nivel = 1;

🧬 8. Identidad de los objetos


Heroe h1 = new Heroe();
Heroe h2 = new Heroe();

h1.nombre = "Artigas";
h2.nombre = "Mago";
  • h1.nombre → "Artigas"
  • h2.nombre → "Mago"

✔️ No se mezclan los datos

✔️ Son objetos diferentes

⚠️ 9. Error común

❌ Pensar que cambiar un objeto afecta a todos

✔️ Cada objeto tiene su propia información

🧩 10. Modelado

Antes de programar, preguntarnos:

  • ¿Qué objeto quiero representar?
  • ¿Qué características tiene?
  • ¿Qué tipo de dato corresponde?

Ejemplo: Monstruo

  • especie → String
  • puntosVida → int
  • esJefeFinal → boolean

🚀 11. Lo que viene

  • Constructores
  • Encapsulamiento
  • Métodos

🧪 Actividad de Autoevaluación

  1. ¿Qué es una clase?
  2. ¿Qué es un objeto?
  3. ¿Para qué sirve new?
  4. ¿Qué diferencia hay entre h1 y h2?
  5. Inventá una clase con 3 atributos

💡 Resumen

  • Clase = molde
  • Objeto = instancia
  • Atributos = características
  • new = crea objetos
  • Cada objeto es independiente

👉 “En POO no pensamos en pasos… pensamos en cosas que interactúan.”
